# Security policy

Oarlock is an independent open-source Elixir SDK for Paddle Billing.

## Report a vulnerability

Report suspected vulnerabilities privately through [GitHub's private vulnerability reporting for Oarlock](https://github.com/szTheory/oarlock/security/advisories/new).
Do not report a vulnerability in a public issue or pull request. Include only
the information needed to explain the impact and reproduce the issue; do not
include real credentials or customer data.

The private reporting route is enabled in this repository. Maintainers review
reports through GitHub. This policy does not promise a response or remediation
time.

## Ownership and response

No person or team is named here as the security owner. A maintainer records
verified ownership and next actions during triage.
