# Phase 20: Local DX & Repository Foundation

## Objective
Establish an isolated, containerized Phoenix 1.7 demo application (`/demo`) that consumes the `oarlock` SDK via a path dependency. Provide a frictionless Local Developer Experience using Docker Compose and Traefik, ensuring the demo can be spun up without local port conflicts or host-level Elixir dependencies.

## Key Files & Context
- `demo/mix.exs`: The Phoenix app configuration.
- `demo/docker-compose.yml`: Infrastructure definition (Postgres, Traefik, Phoenix).
- `demo/Dockerfile`: Container definition for the Phoenix app.
- `demo/priv/repo/seeds.exs`: Idempotent data seeding.

## Implementation Steps

1. **Scaffold the Phoenix Application**
   - Execute `mix phx.new demo --no-umbrella --no-mailer` inside the project root (creating the `/demo` directory).
   - Update `demo/mix.exs` to include the `oarlock` dependency: `{:paddle, path: "../"}`.

2. **Configure Docker Compose & Traefik**
   - Create `demo/docker-compose.yml`.
   - Define a `db` service running PostgreSQL (internal network only, no port 5432 exposure to host).
   - Define a `traefik` service to act as a reverse proxy, exposing port 8000 on the host.
   - Define a `web` service for the Phoenix app, building from `demo/Dockerfile`. 
   - Mount `../` to `/workspace` and working directory `/workspace/demo` in the `web` service for live code reloading.
   - Configure Traefik routing via a `traefik.yml` file provider to route `Host(\`demo.docker.localhost\`)` to the internal Phoenix port (4000).

3. **Configure Database & Ecto**
   - Update `demo/config/dev.exs` and `demo/config/test.exs` to connect to the Docker `db` service using the service name as the hostname.
   - Set up an idempotent `demo/priv/repo/seeds.exs` script that seeds essential initial data.

4. **Verify Boot Sequence**
   - Ensure the `docker-compose.yml` commands run `ecto.setup` on boot.
   - Confirm `docker compose up --build` compiles the app, runs migrations, and exposes the app successfully.

## Verification & Testing
- **FND-01**: Check that `demo/mix.exs` correctly resolves `oarlock` via path dependency and compiles.
- **FND-02**: Verify `curl -H "Host: demo.docker.localhost" http://localhost:8000` responds with the Phoenix start page, and local ports 4000/5432 remain free on the host.
- **FND-03**: Verify `mix run priv/repo/seeds.exs` can be run multiple times without failure (idempotency).
