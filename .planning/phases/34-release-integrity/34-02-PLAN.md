## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Release Please outputs → automatic candidate | Generated tag/version metadata can disagree with the tag's actual target or Mix declaration. |
| GitHub concurrency queue → Hex side effect | Time passes while a job waits; prior tag, proof, and registry observations may be stale. |
| publish environment → Hex step | The environment makes a powerful organization API-write key available. |
