<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller opts -> lifecycle mutation body | Pause mixes user-controlled lifecycle opts with request opts and must not leak unsupported keys into JSON or Req. |
| Caller retry preference -> transport layer | `retry:` should remain the only per-call request option forwarded on pause operations. |
| Subscription ID -> URL path | Subscription identifiers cross into the `/subscriptions/{id}/pause` path and must remain validated/encoded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04 | Tampering | Pause lifecycle opts | mitigate | Split lifecycle opts from request opts explicitly and validate `resume_at` / `on_resume` locally per D-10, D-11, and D-22. |
| T-10-05 | Tampering | Unsupported `idempotency_key:` on pause | mitigate | Raise `ArgumentError` before dispatch when `idempotency_key:` is present per D-21 so false idempotency guarantees never reach callers. |
| T-10-06 | Denial of Service | Retry behavior on mutation calls | mitigate | Keep `retry:` as the only forwarded request opt and prove `retry: false` disables retries with Agent-backed adapter tests per D-20. |
| T-10-07 | Tampering | Subscription path handling | mitigate | Reuse existing subscription ID validation and path encoding helpers when constructing `/pause` URLs. |
| T-10-SC | Tampering | Dependency/install surface | accept | No new packages or installs in this plan. |
</threat_model>
