<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Resource modules → Paddle.Http | Many public call paths must not bypass the central policy. |
| Provider cursor → telemetry context | Signed/query-bearing dynamic URLs are dispatch data, not observability identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-32-04 | Tampering/Repudiation | resource mutations | high | mitigate | Route every mutation through the Plan 32-04 one-attempt/ambiguity contract and remove idempotency claims. |
| T-32-02 | Information Disclosure | pagination labels | high | mitigate | Carry literal operation/template route separately from dynamic cursor URLs and prove canary absence in Plan 32-06. |
| T-32-06 | Denial of Service | resource reads | high | mitigate | No resource owns delays; all reads delegate to the central four-attempt/60000 ms cap. |
| T-32-05 | Spoofing | resource URL construction | medium | mitigate | Preserve existing ID validation/encoding and use the validated client base URL from Plan 32-03. |
| T-32-SC | Tampering | packages | low | accept | No package installation occurs in this expansion plan. |
</threat_model>
