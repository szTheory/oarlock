## Trust Boundaries

| Boundary | Description |
|---|---|
| caller options → public mutation API | Untrusted option containers and values enter a credential-bearing SDK client call. |
| resource module → Paddle.Http/Req | Validated domain data and static internal context are merged before authenticated transport. |

</threat_model>
