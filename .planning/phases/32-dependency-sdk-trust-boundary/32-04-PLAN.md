## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller/resource options → Paddle.Http | Retry and operation context controls transport behavior. |
| Req terminal outcome → Paddle.Error | Uncertain provider state becomes public reconciliation guidance. |
