## Trust Boundaries

| Boundary | Description |
|---|---|
| Resource options → Paddle.Http | Caller-controlled retry/options cross into dispatch policy. |
| Req outcomes → consumer errors | Transport/provider uncertainty becomes public reconciliation guidance. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-32-04 | Tampering/Repudiation | mutation dispatch/idempotency | high | mitigate | Method gate, one mutation attempt, pre-dispatch option validation, complete option removal, and explicit ambiguous outcome. |
| T-32-06 | Denial of Service | Retry-After/retry loop | high | mitigate | GET/HEAD-only transient set, 3 retries/4 attempts, 429-only 60000 ms clamp, deterministic no-sleep tests. |
| T-32-02 | Information Disclosure | Paddle.Error raw_data/guidance | high | mitigate | Redact raw_data and expose only static operation/resource/request identifiers plus fixed guidance atoms. |
| T-32-05 | Spoofing | base URL | high | mitigate | Plan 32-03 validates coherent client state before this boundary. |
| T-32-SC | Tampering | packages | low | accept | No package change occurs in this plan; verified Req floor is inherited from Plan 32-02. |
</threat_model>

- Removal of every idempotency option/header path in Http, Customers, Addresses, Transactions, and Subscriptions.
- Static operation/route labels and deterministic attempt/ambiguity tests for these modules.
