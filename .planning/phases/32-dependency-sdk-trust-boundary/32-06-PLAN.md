<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Req transport → telemetry bus | Secret-bearing transport state becomes observable to arbitrary subscribers unless projected. |
| Concurrent requests → private span state | Attempt/duration state must not cross-contaminate requests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-32-02 | Information Disclosure | telemetry metadata/measurements | high | mitigate | Exact allowlist, static labels, host-only projection, recursive canaries, and structural rejection of transport terms. |
| T-32-04 | Repudiation | per-attempt event pairing | medium | mitigate | Attempt counters and terminal-before-retry ordering prove every physical attempt has one outcome. |
| T-32-06 | Denial of Service | telemetry cardinality | medium | mitigate | Static operations/routes and normalized finite error/result fields exclude IDs and raw paths. |
| T-32-05 | Spoofing | host metadata | medium | mitigate | Emit parsed hostname only from the already validated client URL; omit userinfo/path/query. |
| T-32-SC | Tampering | packages | low | accept | No package installation occurs; existing telemetry dependency/event names are retained. |
</threat_model>
