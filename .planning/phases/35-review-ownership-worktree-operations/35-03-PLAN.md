<interfaces>
The canonical per-item record is a maintainer GitHub issue comment with a fenced `oarlock-triage` block: `Date: YYYY-MM-DD`, `State: needs-triage|needs-info|ready|in-progress|blocked`, `Owner: USER|unknown`, `Scope: in-scope|deferred|out-of-scope`, `Next action: TEXT`, `Action owner: USER`, `Review by: YYYY-MM-DD`, and for needs-info `Information needed: TEXT`. A `needs-triage` state still requires a maintainer's actual scope decision, not an inferred default. The audit accepts a record only if the comment author's current repository permission is admin or write; missing permission evidence is incomplete. The newest candidate triage comment by created_at and numeric ID is current; a malformed newest candidate fails, and same-time incompatible candidates report contradiction. JSON output has inventory counts, per-item facts/diagnostics, and conclusion.
</interfaces>
