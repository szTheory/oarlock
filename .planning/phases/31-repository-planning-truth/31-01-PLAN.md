The new shared result contract is:
- `collectRepositorySnapshot(options)` returns only observed repository/worktree/process facts plus collection errors.
- `evaluateRepositoryInventory(snapshot, registry, options)` adds classifications, proposed dispositions, diagnostics, and an exit code without changing facts.
- `makeDiagnostic(fields)` requires code, severity, artifact, field, expected, actual, authority, evidence, and repair; warnings/intentional exceptions also identify owner or revisit condition.
- `renderHuman(result)` and `renderJson(result)` format the same already-evaluated result and never recollect, filter, or reclassify.
- `exitCodeFor(result)` returns 0 without errors, 1 for policy/invariant errors, and 2 for incomplete or unsafe collection.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Git/process/filesystem output → normalizer | Paths, refs, lock reasons, porcelain bytes, process evidence, and file contents are untrusted local input. |
| Ownership registry → classifier | Human claims may be stale, broad, ambiguous, or malformed and cannot replace observed facts. |
| Normalized result → terminal/JSON consumer | Crafted names or control characters must not spoof diagnostics or diverge between renderers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-31-01 | Tampering / Elevation of Privilege | Git subprocess boundary | high | mitigate | Allowlist inspection-only argument arrays, disable shell interpolation, and prove refs/index/files/worktree metadata unchanged in integration tests. |
| T-31-02 | Spoofing / Information Disclosure | Human renderer | medium | mitigate | Escape terminal control characters and retain raw-safe JSON serialization plus parity assertions. |
| T-31-03 | Tampering / Repudiation | Ownership classifier | medium | mitigate | Require versioned exact selectors, provenance, confidence, revisit date, expiry handling, and blocking ambiguity diagnostics. |
| T-31-04 | Denial of Service | Git/file collectors | medium | mitigate | Bound subprocess buffers and file reads; convert truncation, unreadability, and malformed input into exit-2 diagnostics. |
| T-31-05 | Information Disclosure | Registered linked worktrees | low | accept | Inventory reports paths Git explicitly registers because complete worktree visibility is the local tool's purpose; it does not recursively read unrelated directories. |
</threat_model>
