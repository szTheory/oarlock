## Trust Boundaries

| Boundary | Description |
|---|---|
| Current index/ledger → immutable archives | Repairs may update navigation and append corrections but must never rewrite historical snapshots. |
| Git tags/tagged files → identity model | Local refs and archive prose may be absent or contradictory and cannot prove publication by themselves. |
| Markdown links → repository filesystem | Link targets may be missing, mutable, or escape the repository boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-31-11 | Tampering / Repudiation | Archived milestone history | high | mitigate | Snapshot archive bytes, prohibit archive writes, and require dated current-ledger errata pointing to preserved evidence. |
| T-31-12 | Spoofing / Repudiation | Milestone/package/publication identity | high | mitigate | Source five independent fields, retain unknowns, and test that no field is inferred from another. |
| T-31-13 | Information Disclosure | Archive/link resolver | medium | mitigate | Normalize targets within repository root and report escapes without following arbitrary external paths. |
| T-31-14 | Denial of Service | History enumeration | low | accept | The tracked milestone set is repository-bounded and small; bounded reads and collection-error diagnostics limit malformed inputs. |
</threat_model>
